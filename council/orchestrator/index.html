Not configured? Run the setup wizard:

        
councilkey setup

        
It asks for the model provider (OpenAI / Anthropic / Gemini / OpenRouter),
          stores the API key encrypted, and optionally installs the external agents.

        
Useful commands

        
councilkey agents status      # external agents installed?

        
councilkey agents env         # export stored API keys

        
eval "$(councilkey agents env)"

        
councilkey agents verify      # real ask, shows the backend
